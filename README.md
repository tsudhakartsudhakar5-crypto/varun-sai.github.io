Varun Sai — The Time Changes

A personal static author website for Varun Sai and his book The Time Changes.

Version 3

Version 3 is a refined, responsive version of the website with a stronger visual identity, improved navigation, animations, and a dedicated structure for the author's books and future projects.

Included

- "index.html" — Main website
- "style.css" — Website styling and responsive design
- "script.js" — Website interactions and animations
- "book-cover.png" — The Time Changes book cover
- "README.md" — Project information

Website Features

- Responsive design for mobile and desktop
- Navigation menu
- Hero section
- The Book section
- Transformation journey
- About the Author section
- Future Books section
- Pothi purchase link
- Amazon placeholder
- Automatic copyright year
- Mobile navigation
- Smooth scroll-reveal animations
- Subtle book-cover hover effect
- Accessibility support for reduced-motion preferences
